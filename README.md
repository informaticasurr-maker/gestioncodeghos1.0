# Ejecutar y desplegar tu aplicación de Servicio Técnico con IA

Este repositorio contiene todo lo necesario para ejecutar la aplicación localmente.

## Ejecución Local

**Requisitos previos:** Node.js

1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Configurar la clave `GEMINI_API_KEY` en `.env.local` con tu clave de API de Google Gemini (opcional para el asistente de voz IA).
3. Iniciar la aplicación en modo desarrollo:
   ```bash
   npm run dev
   ```
